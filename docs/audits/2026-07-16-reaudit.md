## Top issues (all verified against source)

### B1 · 🟠 Correctness — per-label threshold degenerates to grid minimum
- **File:** `app/tuning.py` L153–163
- **Problem:** `best_t, best_f1 = best_global, -1.0`; a label with zero positives in
  the val split scores f1=0 at every grid threshold, and `0 > -1` makes the FIRST
  grid entry (0.05) win — the intended `best_global` fallback is always overwritten.
- **Impact:** Split mode + per-label tuning (auto/thorough): labels near
  `min_samples_per_label` that miss the 15% val split are served with a ~0.05
  threshold and fire on much of the traffic. Silent precision loss.
- **Fix:** Skip tuning when `truth.sum() == 0` → keep the global threshold.

### B2 · 🟠 Correctness — Registry.get() re-inserts a just-deleted model
- **File:** `app/registry.py` (get L153–164 vs delete L179–185)
- **Problem:** get's miss path loads under `_disk_lock`, releases it, then inserts
  into the cache under `_lock` only. A delete landing between leaves the deleted
  model cached; `import_zip` never touches the cache, so delete X → re-import X →
  `get()` serves the OLD weights indefinitely. `save()` explicitly closes this
  exact window; `get()` violates the same invariant.
- **Fix:** Run the miss-path read + cache insert while holding `_disk_lock`
  (nesting `_lock` inside — the documented legal ordering, mirrors `save()`).

### C1 · 🟠 API — /datasets/{name}/validate turns user input errors into 500
- **File:** `app/routes/datasets.py` L109–129
- **Problem:** Unlike its siblings, `validate` has no `except TrainingInputError`
  → empty/malformed CSV or wrong separator hits the generic 500 handler.
- **Fix:** Same `→ HTTPException(400, str(exc))` mapping as `analyze`.

### SEC1 · 🟡 Security — single-char separator guard on 1 of 4 inputs
- **Files:** `app/schemas.py` L57/L129, `app/routes/datasets.py` L116
- **Problem:** Only `dataset_info` guards; `/train`, `/datasets/analyze`,
  `validate` pass multi-char separators to pandas (python engine → regex →
  catastrophic backtracking possible; in `/train` it hangs the training thread
  where `should_stop` is never consulted → all future trainings 409 until restart).
  The CHANGELOG claims this fix as done — an overclaim.
- **Fix:** `Field(min_length=1, max_length=1)` on both schemas + Query constraint
  on validate; correct the CHANGELOG wording.

### C6 · 🟡 Frontend — inline `onfocus` handler blocked by our own CSP
- **File:** `app/static/ui/manage.js` L17–18
- **Problem:** The share box injects `onfocus="this.select()"` via innerHTML; the
  UI's CSP has no `'unsafe-inline'` for scripts → violation logged, select-on-focus
  never works. The "zero CSP violations" live check never opened the share box.
- **Fix:** `addEventListener("focus", …)` like the adjacent buttons; add a test
  that greps the UI sources for inline event handlers.

### C7 · 🟡 Frontend — bundle-controlled metadata rendered unescaped
- **File:** `app/static/ui/manage.js` L45–47
- **Problem:** `metadata.n_labels` interpolated into innerHTML without `esc()`;
  `metrics.f1_macro.toFixed(3)` assumes a number. `metrics.json` content is NOT
  schema-validated on import → an imported bundle can inject HTML into the admin
  page (CSP stops script, not phishing markup) or crash the Models tab.
- **Fix:** `esc()` every interpolated value; `Number.isFinite` guard before toFixed.

### D7 · 🟡 Dependencies — `joblib` directly imported, never declared
- **File:** `app/deploy.py` L21 vs `pyproject.toml`/`requirements.txt`/`requirements.lock`
- **Problem:** Direct runtime import satisfied only transitively via scikit-learn;
  the documented dev install leaves its version unconstrained, and the lock-parity
  test ("the 12 direct pins") cannot see it.
- **Fix:** Declare + pin (13 direct deps); bump the parity test count.

### B6 · 🟡 Performance — admin model routes block the event loop
- **File:** `app/routes/models.py` L60–157, `app/routes/datasets.py` L155–157
- **Problem:** export/import/delete/share-download run multi-second zip/skops/rmtree
  work directly in async handlers; predict got `asyncio.to_thread` (T5), these did
  not. A big export freezes `/health` → probe failures can restart the pod.
- **Fix:** Same `asyncio.to_thread` pattern (registry is thread-safe by design).

### D1 · 🟡 Testing — suite not hermetic against ambient env
- **File:** `tests/conftest.py`
- **Problem:** Pre-existing `APIV3_*` vars or a `.env` (which the compose quickstart
  tells users to create!) leak into the suite — empirically shown to fail two tests.
- **Fix:** Session-scoped scrub of stray `APIV3_*` vars before the app imports.

### B4 · 🟡 Correctness — hard-stopped zombie save vs same-name import
- **Files:** `app/routes/models.py` L118–121, `app/registry.py` L121–128
- **Problem:** The import guard keys on job *status*; after `stop(hard=true)` the
  status is idle while the abandoned thread still saves → both stage the same
  `.name.tmp` → mutual clobber, possible franken-bundle.
- **Fix:** Guard on thread liveness + last model name (`active_model_name()`).

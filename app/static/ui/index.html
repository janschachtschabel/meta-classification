What do the results mean?

The model reads your text and estimates for every label how well it fits — a number between 0 and 1 (the confidence, shown as bar + number).

  • Top-k empty: you only get labels the model actually stands behind — everything above its learned decision line. One label can be the honest answer; several labels are fine too (e.g. a text about both physics and electronics).
  • Top-k = N: you always see the N most likely labels, even weak ones. Dimmed entries marked below threshold are guesses the model would not claim on its own.
  • diff: how much of the confidence comes from your text rather than from the label simply being common. Near zero = the model is guessing, not reading.
  • First query after a server start can take ~30 seconds — the model is being loaded from disk. After that, answers come in milliseconds.

How does training work?

The system learns from the examples in your CSV: it reads the text columns and learns which label values belong to which kind of text. Afterwards it can label new texts on its own.

  • Text columns: what the system reads — title, description and keywords together usually work best.
  • Label fields: the column(s) holding the correct answers. Several fields = one separate model per field, trained one after another.
  • Profile: fast = quick low-quality test · auto = recommended · thorough = best quality, slowest.
  • Evaluation: how quality is measured honestly. The split keeps part of the data aside as an unseen exam. Cross-validation lets every row be both study material and exam — better for smaller datasets, takes several times longer.
  • Label filter: keep only labels containing this text — e.g. restrict training to one vocabulary.
  • A running training slows nothing down for others: it is limited to ~60% of the machine and can be stopped at any time.

How to read the scores

F1 (0–1) says how well the model's answers matched the correct answers on data it never learned from — 1.0 would be perfect, ~0.8 is very usable in practice. micro is the overall hit rate (frequent labels count more); macro treats rare labels as equally important and is therefore usually lower. Share link creates a download link that works without an API key and expires after 24 hours; Download/Import move a model between servers as a ZIP file.

What belongs in the CSV?

One row per item. Text columns (title, description, …) plus at least one column with the correct labels — several labels in one cell are separated by commas. Semicolon-separated, UTF-8. Duplicate texts are removed automatically before training, so the row count used for training can be lower than the file's.
